# 게임 기획

## 목표와 제약

- 작업명: 나 혼자만 서바이벌(사용자 결정, 2026-11-08)
- 2026-11-07에 시작해 2026-11-21까지 제작하는 2D 게임이다(사용자 결정, 2026-11-08).
- 넷마블네오 AI 인턴십 지원용 포트폴리오를 목적으로 하며, 게임 제작과 그 과정의 기록을 함께 담는다.
- 하루 작업 시간은 최소 3시간이며, 계획은 하루 약 9시간이다(사용자 결정, 2026-11-08).
- Godot과 Codex로 구현하고, Claude Pro는 기획·명세·회고를 보조한다.
- 역할: 구현은 Codex가 맡는다. 최종 결정과 직접 플레이 검증은 사용자가 한다. 기획과 개발 기록은 Claude를 주 대화 상대로 진행한다.
- 스크립트 언어는 GDScript이다.

## 확정된 방향

- 콘셉트: 그림자 군단을 소재로 직접 제안하는 신규 미니게임이다. 기존 게임을 재현하는 것이 아니다.
- 장르: 뱀서라이크(생존형 액션)이다(사용자 결정, 2026-11-08).
- 화면은 PC 가로형이다(사용자 결정, 2026-11-08).
- 소재·세계관 레퍼런스는 '나 혼자만 레벨업', 플레이 레퍼런스는 '탕탕특공대'다(사용자 결정, 2026-11-08).

## 전체 뼈대 (사용자 확정, 2026-11-08)

세부 수치와 콘텐츠 종류는 시스템별 기획에서 정한다. 아래는 규칙과 구조다.

### 핵심 재미

성장 체감, 선택의 고민, 아슬아슬한 생존, 조합의 발견 네 가지를 모두 목표로 한다. 여기에 더해 선택지에서 고른 그림자 병사를 키우는 재미를 중심에 둔다. 우선순위는 정하지 않았으며, 범위를 줄여야 할 때 정한다.

### 한 판의 흐름

1. 맨몸으로 시작한다. 맨몸은 그림자와 선택지 강화가 없는 상태를 뜻하며, 기본 공격은 처음부터 보유한다. 기본 스킬의 시작 해금 여부는 시스템 5의 skill.csv Initially_unlocked로 정한다(사용자 결정, 2026-11-09).
2. 적이 화면 밖 사방에서 생성되어 플레이어를 향해 이동한다.
3. 기본 공격은 자동으로 발동하고 자동 조준한다. 기본 스킬은 키를 눌러 사용한다. 그림자 소환수는 알아서 싸운다.
4. 몬스터를 처치하면 그 자리에 경험치가 떨어진다. 떨어진 경험치를 획득해야 적립된다. 처치 즉시 자동 지급이 아니다.
5. 레벨업하면 선택지와 강화 포인트를 모두 받는다.
6. 시간이 지날수록 적이 강해지고 수가 늘어난다.
7. 경과 시간을 조건으로 중간 보스가 등장한다.
8. 경과 시간을 조건으로 최종 보스가 등장한다. 최종 보스 등장 이후에는 일반 적이 추가로 생성되지 않으며, 이미 생성된 적은 제거되지 않고 남는다.
9. 최종 보스를 처치하면 완료, 플레이어가 사망하면 실패로 종료한다.

목표 플레이타임은 한 판 15분이다. 15분은 목표치이며 자동 종료 시각이 아니다. 시간이 지나도 자동으로 끝나지 않는다.

### 전투 구성

- 기본 공격: 자동 발동, 자동 조준
- 기본 스킬: 쿨타임 기반, 키 입력으로 사용
- 그림자 소환수: 자동 전투
- 그림자 각성 스킬: 쿨타임 기반, 자동 사용, 자동 조준

플레이어가 직접 하는 조작은 이동, 기본 스킬 키 입력, 그리고 기본 스킬 아이콘 마우스 클릭이다.

### 성장 구조

레벨업 한 번에 레벨업 선택지와 강화 포인트를 모두 받는다. 번갈아 지급되는 구조가 아니다. 지급은 함께이고 사용처는 서로 다르다.

- 레벨업 선택지: 3개가 제시되고 그중 1개를 선택한다. 다시 뽑기는 있고 건너뛰기는 없다.
- 선택지에 들어가는 것: 그림자, 기본 공격 강화, 그 외 효과. 기본 스킬의 획득과 강화는 선택지에 나오지 않는다.
- 강화 포인트: 기본 스킬의 해금과 강화에만 쓴다(2026-11-09 변경). 강화 포인트를 가진 상태에서 플레이 중 기본 스킬 아이콘을 마우스로 클릭하면 해당 스킬이 레벨업한다. 레벨업 순간이나 판 종료 후로 제한하지 않는다.

강화 경로 정리:
- 기본 공격 → 레벨업 선택지
- 기본 스킬 → 강화 포인트 전용
- 그림자와 그 외 효과 → 레벨업 선택지

### 그림자

- 그림자는 선택 스킬 개념이되 형태는 소환수다.
- 레벨업 선택지에서 얻으며, 그림자가 아닌 강화와 같은 선택지에서 경쟁한다.
- 그림자는 5종이며 채용 한도는 3이다. A단계는 이그리트 1종이다(사용자 결정, 2026-11-09). 한도가 차면 채용되지 못한 그림자는 선택지에 더 이상 나오지 않는다.
- 이후 선택지에는 채용된 그림자가 나오고, 반복해서 고르면 레벨이 오른다.
- 강화되는 것은 소환수 자체다. 데미지, 스킬 범위 등이 오른다. 발사체 개수나 스킬 크기가 커지는 방식이 아니다.
- 최대 레벨에 도달하면 그림자 각성으로 그림자가 자체 스킬을 가진다. 이 스킬은 쿨타임 기반이며 자동으로 사용되고 자동 조준한다.

### 전투와 피격

- 플레이어는 체력을 보유한다. 체력이 0이 되면 사망하고 해당 판은 실패로 종료한다.
- 몬스터는 근거리형과 원거리형이 모두 존재한다. 적과 접촉했을 때도 데미지를 입는다.
- 재피격 제한은 몬스터 개체별로 적용한다. 특정 몬스터에게 데미지를 입으면 일정 시간 그 동일한 몬스터에게 다시 데미지를 입지 않는다. 한 번 피격되었다고 모든 몬스터의 공격에 대해 공통 무적이 되는 방식이 아니다.

### 맵

- 맵은 한 화면보다 넓다. 무한 맵이 아니며 이동 가능 범위에 한계가 있다.
- 적은 화면 밖 사방에서 생성되어 플레이어를 향해 이동한다.

## 데이터 관리 원칙

- 게임 데이터는 코드에 직접 적지 않고 테이블로 관리한다. 테이블은 엑셀에서 작성해 CSV로 내보낸다.
- 데이터 테이블은 별도 시스템으로 두지 않고, 테이블이 필요한 시스템이 소유한다. 시스템 파일의 '테이블' 항목에 CSV 이름, 열, 형식, 예시 행을 정의하고, 다른 시스템은 ID로 참조한다.
- 모든 CSV가 따를 공통 약속(사용자 확정, 2026-11-08, 시스템 1에서 결정):
  - 파일 위치: `res://data/` 아래에 둔다.
  - CSV를 엑셀로 직접 열어 편집한다. 별도의 `.xlsx` 원본은 두지 않는다. 그래서 BOM 포함 저장이 필수다. 열의 의미와 입력 지침은 각 시스템 문서의 '테이블' 항목에만 두며, 그곳이 단일 출처다.
  - 인코딩: UTF-8 BOM 포함으로 저장한다. 읽는 쪽에서 BOM을 제거한다. BOM 없이 저장하면 한국어 윈도우의 엑셀이 CP949로 읽어 한글이 깨지고, 그 상태로 저장하면 원본이 손상된다(2026-11-08 확인).
  - 구분자: 쉼표. 값에 쉼표가 있으면 큰따옴표로 감싼다.
  - 첫 줄: 열 이름. 전체 이름의 첫 글자만 대문자로 쓰고 단어 구분은 밑줄로 한다. 예: `Id`, `Name_ko`, `Move_speed`, `Note`.
  - 첫 열: `Id`. 파일 안에서 중복 불가.
  - 자료형 표기: `String`, `Int`, `Float`, `Bool`(0 또는 1), `Path`(`res://` 경로), `Enum`.
  - 숫자 표기: 엑셀이 저장하는 표기로 쓴다. 소수 끝의 0과 끝에 남는 소수점을 쓰지 않는다(3.0이 아니라 3, 0.20이 아니라 0.2). 엑셀로 열어 저장해도 값과 글자가 바뀌지 않게 하기 위함이다(사용자 결정, 2026-11-09).
  - `Enum`은 정해진 허용값 목록 중 하나를 쓰는 자료형이다. 허용값 목록은 해당 시스템 문서의 테이블 정의에 명시한다. 엑셀과 CSV에는 식별값을 문자열로 적고, 읽을 때 유효성을 검사해 코드 내부 Enum으로 변환한다. 허용값 목록에 없는 값이면 CSV 오류로 처리한다(사용자 확정, 2026-11-08).
  - 빈 값: 빈 칸으로 두고 읽는 쪽에서 기본값으로 처리한다.
  - 설명 열: `Note` 열을 둘 수 있다. 게임은 읽지 않는다.
  - 주석 줄: 쓰지 않는다. 설명은 `Note` 열에만 적는다.
  - 읽는 방식: 게임 시작 시 한 번에 모두 읽어 보관하고 플레이 중 다시 읽지 않는다.
- 예외: 맵의 가로·세로는 테이블로 관리하지 않고 맵 씬에 고정값으로 둔다(사용자 결정, 2026-11-08). 맵 에디터로 제작하기 때문이며, 밸런스 수치가 아니라 레벨 디자인 산출물이다.
- 사용자 PC에 Excel이 있어 CSV로 저장할 수 있다(사용자 보고, 2026-11-07). 시스템 1에서 UTF-8 BOM 저장, Godot의 `.csv` 원본 유지와 내보낸 실행 파일에서 CSV 읽기를 확인했다.
- 역할을 구분한다. 코드는 데이터를 읽고 규칙과 동작을 실행한다. 엑셀은 콘텐츠 데이터 작성·수정의 원본이다. CSV는 게임이 읽는 데이터 파일이다.
- 밸런스와 콘텐츠 설정 수치는 코드에 직접 쓰지 않는다. 대상 예: 플레이어와 몬스터의 체력·이동 속도, 공격과 스킬의 데미지·범위·쿨타임, 경험치 요구량, 강화 비용과 단계별 효과, 적 생성 수·주기, 보스 등장 시간.
- 새로운 동작의 구현과 기존 동작의 수치 조정을 구분한다. 수치 조정만으로 가능한 작업은 코드 요청이 아니라 테이블 수정으로 처리한다.
- 사용자 결정으로 하드코딩하는 예외(S7-FIX-01, 2026-11-10): 그림자 간 이동 조향의 SHADOW_SPACING은 shadow_actor.gd의 const 한 곳에 둔다. 16px는 제안·미확정 시작값이며 밀어내기 간격을 정하는 값이 아니다. 적-그림자 분배 Enemy_push_share는 CSV로 관리한다.

## 비주얼·사운드 방향

- 색감은 검정 바탕에 보라색 발광이다. 연출은 크게 중요하지 않으며 최소로 한다.
- 그림과 사운드는 AI(이미지 생성, 사운드 생성)를 활용해 만든다. 규칙이 정해지기 전에는 임시 도형으로 만들고, 마지막에 입힌다.
- 생성 도구와 방법은 기록으로 남긴다.

## 레퍼런스

- 그림자 군단 컨셉 자료(웹툰 표지, 군단 컷, 게임 홍보 이미지): 검정과 보라색 발광, 폐허 배경, 크기로 위계를 보여 주는 군단의 느낌을 참고한다.
- 플레이 레퍼런스: 탕탕특공대. 레벨업 선택지로 능력을 쌓아 가는 구조를 참고한다. 다만 선택 스킬의 강화 방향은 다르다. 발사체 개수나 스킬 크기를 키우는 대신 소환수 자체를 강화한다. 장비, 재화, 상점, 판 사이 성장 등 레퍼런스의 다른 요소는 채택하지 않았다.
- 자료 속 규칙은 이 게임의 규칙으로 자동 채택하지 않는다.

- 확정: 그 외 효과에 경험치 획득 반경 증가와 체력 회복(빈자리 보충용)을 포함한다(사용자 결정, 2026-11-09).
- 미정: 최종 수치와 나머지 그 외 효과(쉴드 등).
- 확정: 선택지별 Weight로 등장 가중치를 관리한다. 다시 뽑기는 판당 횟수를 choice_rule.csv에서 관리하며 비용이 없다(사용자 결정, 2026-11-09).

### 강화 포인트와 기본 스킬
- 확정: 기본 스킬 4종(질주·난도·은신·드래곤 피어), 해금·강화 비용은 항상 1포인트다(사용자 결정, 2026-11-09).
- 확정: 최대 레벨은 스킬별 레벨 테이블의 마지막 Level이다. 난도 테스트값은 5다. 아이콘은 화면 오른쪽 아래 임시 배치다(사용자 결정, 2026-11-09).
- 확정: 질주·은신·드래곤 피어의 상세 규칙은 시스템 5 문서를 따른다(사용자 결정, 2026-11-09).
- 미정: 세 스킬의 최종 수치. 승인된 A단계 시작값은 검증용이다.
- 확정: 레벨업 1회당 강화 포인트 1개(사용자 결정, 2026-11-09, 시스템 4)

### 전투
- 플레이어 체력, 적 공격력, 기본 공격 수치, 재피격 제한 시간: A단계 시작값을 정했다. 최종 밸런스는 B단계에서 정한다.

### 시간 진행
- 중간 보스와 최종 보스의 등장 시점과 횟수
- 시간대별 적 강화·증가 수치
- 최종 보스 등장 후 장기전이 될 때의 추가 규칙(보스 강화 여부 등)
- 최종 보스전에서 일반 적 생성이 중단되어 경험치 공급이 줄어드는 점을 그대로 둘지
- 목표 플레이타임 15분에 맞추는 세부 시간 설계

- 적의 종류 구성: 초기 2종으로 확정(사용자 결정, 2026-11-08). 두 적의 구체적 특성과 근거리·원거리 구성은 미정이며 시스템 2 B단계에서 정한다.
