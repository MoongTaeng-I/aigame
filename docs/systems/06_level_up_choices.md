## 개요

레벨업 신호마다 선택 기회를 하나씩 쌓고, 게임을 멈춘 채 카드 중 하나를 고르게 한다. 고른 선택지의 레벨을 올리고 효과를 적용한다.
경계: 레벨업 신호와 포인트는 시스템 4. 그림자 선택지의 소환·레벨은 시스템 7(같은 구조에 연결). 그림자 각성 스킬은 범위에서 제외(2026-11-12 사용자 결정, 개발 시간 부족)한다. 정식 HUD는 시스템 9.

## 규칙

### 진행
1. 시스템 4의 레벨업 신호 1회마다 선택 기회 1개를 대기열에 쌓는다.
2. 대기열이 비어 있지 않고 플레이어가 살아 있으면 선택 화면을 띄우고 게임 전체(적, 투사체, 쿨타임, 진행 중인 스킬 효과 등)를 멈춘다. 선택 화면 UI는 멈춘 동안에도 동작한다.
3. 카드는 마우스 클릭으로 고른다. 클릭하면 바로 선택된다(확인 버튼 없음). 건너뛰기는 없다.
4. 하나를 고르면 대기열에서 하나를 빼고, 남아 있으면 게임을 재개하지 않은 채 곧바로 다음 카드를 뽑아 표시한다. 대기열이 비면 게임을 재개한다.
5. 선택 화면이 떠 있는 동안 스킬 아이콘 클릭(해금·강화)은 막는다.
6. 플레이어가 사망한 상태에서는 대기 중인 선택이 있어도 선택 화면을 띄우지 않는다. 사망 처리가 우선한다.

### 후보와 뽑기
7. 일반 선택지 = choice.csv에서 Effect가 heal이 아닌 것. 현재 레벨이 최대 레벨(그 선택지 레벨 행의 마지막 Level) 미만인 것만 후보다.
8. 일반 후보가 4개 이상이면 Weight 비율로 중복 없이 3개를 뽑는다.
9. 일반 후보가 3개 이하이면 그 후보를 모두 표시하고, 남은 자리를 체력 회복 카드로 채운다(3개 → 3장, 2개 → 2장+회복 1장, 1개 → 1장+회복 2장, 0개 → 회복 3장). 회복 카드는 같은 화면에 중복될 수 있고, 일반 선택지는 한 화면에 중복되지 않는다. 일반 카드를 먼저, 회복 카드를 뒤에 놓는다.
10. 체력 회복은 가중치 추출에 참여하지 않는다(보충용).

### 다시 뽑기
11. 판당 다시 뽑기 횟수는 choice_rule.csv의 Reroll_count이며, 판 시작 시 한 번 주어진다. 레벨업마다 새로 주지 않는다. 추가 획득은 없다. 비용은 없고 강화 포인트를 쓰지 않는다.
12. 다시 뽑기를 누르면 횟수를 1 줄이고 같은 규칙(8~10)으로 다시 뽑는다. 직전 결과와 같은 카드가 다시 나와도 된다(제외·우선 추출 없음).
13. 일반 후보가 3개 이하이거나 남은 횟수가 0이면 버튼을 비활성화하고, 눌러도 횟수가 줄지 않는다.

현재 데이터 메모(사용자 결정, 2026-11-09): 일반 선택지가 정확히 3개이므로 다시 뽑기는 게임 안에서 항상 비활성이다. 규칙 13은 유지한다. 다시 뽑기의 실행 동작은 P0로만 검증했으며, 직접 플레이 확인은 시스템 7에서 그림자 카드가 추가되어 일반 후보가 4개 이상이 될 때 한다.

### 그림자 카드 연결 (S7-IMPL-02)

종류당 1마리는 시스템 7의 확정 규칙이다. 이그리트/베르(내부 Id는 임시)는 각각 소환 1행(Level 1, Value 1)만 두는 제안 구조로 기존 최대 레벨 제외(규칙 7)를 사용한다. 한 번 선택한 종류는 후보에서 빠지고 채용 한도 3은 서로 다른 종류 3종이다. 카드 1행은 현재 소환 전용 검증 구조이며 소환수 최대 레벨 확정으로 해석하지 않는다. 확정 기획(2026-11-12 사용자 결정): 그림자는 선택지에서 반복 선택 시 레벨이 오르고, 최대 레벨에 도달하면 시스템 6 규칙 7에 따라 후보에서 제외된다. 성장 세부·최대 레벨 수치는 미정이고 성장 구현 완료를 뜻하지 않는다. 그림자 각성 스킬은 범위에서 제외(2026-11-12 사용자 결정, 개발 시간 부족)한다. Effect에 shadow_igrit / shadow_charger_test를 연결하고 임시 카드 Weight 10을 시작값으로 쓴다. 임시 종류는 정식 종류 확정 시 정리 방법을 정한다. 규칙 13은 그대로이며 이번 데이터의 일반 후보는 처음 5개, 두 그림자 선택 후에는 최대 3개가 남는다. 직접 다시 뽑기 확인은 미기록 상태다.

### 효과
14. 선택지를 고르면 레벨이 1 오르고, 효과값은 그 레벨 행의 Value(그 레벨까지의 누적 변화량)다. 비율이 아닌 고정값이다.
15. attack_range_add: 기본 공격 Range = basic_attack.csv의 Range + Value. 공격 도중 바뀌면 다음 공격부터 적용한다(진행 중인 공격의 둘째 타는 시작 시 범위).
16. attack_interval_sub: 기본 공격 Interval_sec = basic_attack.csv의 Interval_sec − Value. 다음 공격의 대기 시간 계산부터 적용한다.
17. pickup_radius_add: 경험치 획득 반경 = player.csv의 Pickup_radius + Value. 즉시 적용한다.
17-1. attack_targets_add(BAL-02): 기본 공격의 동시 대상 수 = 1 + Value. 일반 공격의 각 타격에서 기존 첫 대상 선택 규칙(체력 낮은 순 → 가까운 순 → 생성 순, 같은 사거리)으로 서로 다른 대상을 최대 1+Value명 고르고, 대상마다 그 방향으로 같은 삼각형 판정과 베기/찌르기 이펙트를 낸다. 한 타격에서 여러 삼각형에 겹친 적은 피해·넉백을 1회만 받는다. 대상이 부족하면 있는 만큼만 친다. 선택한 뒤 다음 타격부터 적용한다. 소리·그림 내딛기·당김은 첫 대상 기준 1회다.
17-2. max_hp_pct_add(FIX-04): 최대 체력 = player.csv Max_hp × (1 + Value/100), 정수 반올림(0.5는 올림). 선택 순간 늘어난 최대 체력만큼 현재 체력도 함께 늘린다(감소 없음, 최대 초과 없음). 회복 선택지·피해·사망은 새 최대 체력 기준이다.
18. heal: 레벨이 없는 단발성이다. 고르는 즉시 최대 체력 × Value% 를 회복한다(정수가 아니면 내림). 최대 체력을 넘는 분량은 버린다. 최대 체력일 때도 고를 수 있다(회복량 0).

## 예외 처리

CSV 오류는 게임을 멈추고 화면에 표시한다.
- choice.csv: Effect가 허용값(attack_range_add, attack_interval_sub, pickup_radius_add, heal, shadow_igrit, shadow_charger_test, shadow_belion, attack_targets_add, max_hp_pct_add)이 아님, heal 행이 정확히 1개가 아님, heal의 Weight가 0이 아님, 일반 선택지의 Weight가 1 미만.
- choice_level.csv: Choice_id가 choice.csv에 없음, 일반 선택지의 레벨 행이 없거나 Level이 1부터 이어지지 않음, heal의 레벨 행이 1개가 아니거나 Level이 1이 아님, heal의 Value가 0 이하 또는 100 초과, 일반 선택지 Value가 0 미만.
- choice_level.csv: attack_targets_add 선택지의 Value가 1 미만이거나 정수가 아님(BAL-02).
- choice_level.csv: max_hp_pct_add 선택지의 Value가 유한한 양수가 아님(FIX-04).
- 그림자 카드(shadow_igrit/shadow_charger_test)는 소환 1행(Value 1)이어야 한다. 추가 레벨 성장 구현은 아직 없으며 현재 검증 구조와 맞지 않는 행은 오류다. 반복 선택 성장의 확정 기획과 현재 소환 전용 구현을 구분한다.
- attack_interval_sub의 모든 Value에 대해 basic_attack.csv의 Interval_sec − Value가 0 미만이면 오류.
- choice_rule.csv: choice_rule_01이 없음, Reroll_count가 0 미만.

## UI

참고 이미지 3장 중 세 번째가 기본 틀이다. 구도만 참고하고 그림·로고는 가져오지 않는다. 검정 바탕·보라 발광이다.
- 반투명 어두운 배경 위 상단에 리본 모양 제목 띠 "레벨업! 능력 선택".
- 세로 카드 3장을 가로로 배치. 각 카드: 이름 띠 / 아이콘 자리(임시 도형) / 효과 설명 상자(다음 레벨의 Desc_ko) / 레벨 칸.
- 레벨 칸: 최대 레벨 수만큼 네모를 그리고 현재 레벨까지 채우며, 이번에 오를 칸을 강조한다. "Lv 2 → 3"처럼 글자도 함께 쓴다.
- 체력 회복 카드: 레벨 칸 대신 "체력 72 → 100 / 100"(선택 시 결과)을 쓰고, 이름 띠 색을 성장 카드와 다르게 한다.
- 마우스를 올린 카드는 테두리가 밝게 빛난다.
- 카드 아래 큰 버튼 "다시 뽑기 (남은 횟수/전체 남음)". 비활성일 때 어둡게 표시한다.
- 제한 시간, 건너뛰기, 확인 버튼은 넣지 않는다.
