## 개요

플레이어가 맵 위를 이동하고 카메라가 따라오는 기반을 만든다. 더해서 모든 시스템이 사용할 CSV 읽기 공통 기능을 구현하고, 모든 CSV가 따를 공통 약속을 확정한다. 공통 약속의 내용은 `game_design.md`의 데이터 관리 원칙에 둔다.

## 규칙

1. 창은 1280×720 가로 창 모드로 고정한다. 전체화면과 창 크기 변경은 지원하지 않는다.
2. 맵은 직사각형이며 창보다 크다. 맵의 가로·세로는 맵 씬에 고정값으로 둔다. 테이블로 관리하지 않는다. 맵 에디터로 제작하기 때문이며, 데이터 관리 원칙의 의도적 예외다.
3. 플레이어는 맵 중앙에서 시작한다.
4. 이동 입력은 WASD만 받는다. W는 위, A는 왼쪽, S는 아래, D는 오른쪽이다. 방향키는 이동에 쓰지 않는다.
5. 8방향 이동을 허용하며, 대각선 이동 속도는 직선 이동 속도와 같다. 입력 벡터를 정규화해 처리한다.
6. 이동 속도는 `player.csv`의 `Move_speed`에서 읽는다. 코드에 직접 쓰지 않는다.
7. 플레이어는 맵 밖으로 나갈 수 없다. 맵 경계에서 막힌다.
8. 카메라는 플레이어를 화면 중앙에 둔다. 단 카메라가 맵 밖을 비추지 않도록 맵 경계에서 멈춘다. 그 결과 플레이어가 맵 끝에 가까우면 화면 가장자리 쪽에 보인다.
9. CSV 읽기 공통 기능은 게임 시작 시 `res://data/` 아래의 CSV를 모두 읽어 ID로 조회할 수 있게 보관한다. 플레이 중 다시 읽지 않는다.
10. 플레이어 표시는 `player.csv`가 연결한 이동·대기 4×3 시트를 나누어 사용한다. 두 시트 모두 아래·위·오른쪽 행을 사용하고 왼쪽은 오른쪽 행을 좌우 반전한다. 이동 입력에서 절댓값이 큰 축을 우선하며 같으면 세로 방향이다. 이동 중에는 이동 시트를 `Anim_fps`, 정지·빙결·두려움 시전 등 이동 불가 중에는 마지막 방향의 대기 시트를 `Idle_fps`로 반복한다. 상태가 바뀌면 해당 시트 첫 칸부터 시작한다. 이동 시트가 없으면 기존 원형 표시로 대체하고 대기 시트만 없으면 이동 시트 첫 칸으로 멈추며, 이동·충돌·공격 판정은 바꾸지 않는다.

## 예외 처리

- 반대 방향이 동시에 입력되면(왼쪽과 오른쪽 등) 상쇄해 해당 축으로 움직이지 않는다.
- 맵 경계에 닿은 상태에서 이동 입력이 있으면, 경계를 향하는 성분만 차단하고 경계와 평행한 성분은 유지해 벽을 따라 이동한다. 경계에 수직으로만 입력하면 움직이지 않는다. 남은 성분을 다시 정규화하지 않으므로 벽을 따라가는 속도는 직선 이동보다 느리다. 관성 이동이 아니며 입력을 떼면 즉시 멈춘다.
- CSV 파일이 없거나, 필요한 열이 없거나, 값의 자료형이 맞지 않거나, `Id`가 중복되면 게임을 즉시 멈추고 화면에 오류 내용을 표시한다. 기본값으로 대체하지 않는다.

### LOOK-01 설원 숲 던전(2026-11-15 사용자 결정)
