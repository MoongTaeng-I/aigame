  - 접촉에 의한 밀어내기와 공격에 의한 넉백을 별개로 구분한다.
  - 적도 맵 경계에서 막힌다. 밀리는 과정에서도 맵 밖으로 나가지 않는다.
  - 동시 존재 수에 상한을 두고, 상한을 넘기게 되는 수량은 생성하지 않는다.
  - 화면 밖에 연속 n초 머문 적은 플레이어 주변으로 재배치한다. 재배치는 신규 생성과 다른 기능이며, 기존 개체의 위치만 옮기므로 전체 수가 늘지 않고 상한의 남은 자리를 쓰지 않는다. 상한 도달 상태에서도 가능하다.
  - 재배치 위치 규칙은 신규 생성과 동일하며 위치 계산 기능을 공유한다. 화면에 다시 들어오면 체류 시간을 0으로 초기화한다. 체력과 전투 상태는 유지한다.
  - 밀어내기는 매 프레임 한 번만 처리하고 완전 분리를 보장하지 않는다. 적이 몰릴 때 일부 겹침을 초기 구현에서 허용하고, 실제 테스트에서 성능과 밀집 상태를 확인한다.
  - 생성 가능한 방향이 하나도 없으면 그 주기에는 생성하지 않고 넘어간다. 현재 맵 크기에서는 발생하지 않지만 맵 크기를 바꿀 경우를 대비한 안전장치다.
  - `spawn.csv`의 시간대가 겹치면 겹친 행을 모두 적용해 여러 적 종류가 동시에 나오게 한다. 어떤 행도 해당하지 않는 시각에는 생성하지 않는다. 둘 다 오류로 처리하지 않는다. 겹침은 여러 종류를 동시에 내보내는 데 쓰고, 빈 구간은 소강 상태로 쓴다.
  - 생성 규칙은 `spawn.csv` 한 곳에서만 관리하고, 보스 등장 시점과 적 강화 배율은 시스템 8의 `stage_timeline`에 둔다. 같은 규칙을 두 테이블에 중복하지 않는다.
  - 최종 보스 등장 후 일반 생성 중단은 시스템 8이 조건을 판정해 신호를 보내고 시스템 2가 신규 생성을 멈추는 구조로 한다. 조건 판정과 생성 동작을 중복 구현하지 않는다.
